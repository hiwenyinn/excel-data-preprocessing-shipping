第二章 · 核心概念

資料前處理之基本常識與 GIGO 定律

!

航運髒資料的危害

提單號碼多一個空格、英文大小寫混亂、日期格式多元 (如 2024/05/01 與 2024.05.02)。

後果：樞紐分析失真、重複請款、報關退單
範例：" Kaohsiung " ≠ "Kaohsiung"
⚓

GIGO 與 SOLAS VGM

「垃圾進，垃圾出 (GIGO)」。毛重欄若混入文字 N/A 或單位 kg，加總會變成 0 或 #VALUE!。

衝擊：船舶配載重心配重失衡、違反國際法規遭扣船
海事規範：國際海事組織 SOLAS 貨櫃總重驗證
✓

Tidy Data 乾淨六守則

  • • 絕不使用合併儲存格 (分析大忌)
  • • 首列維持單一標題列 (Header)
  • • 一列一訂艙實體，一欄單一屬性
  • • 底層資料不留人工小計列
  • • 杜絕排版用空白空列
達成標準化結構，利於隨時樞紐分析
第二章 / 第三章 · 函數精華

航運文字與數據清洗四大核心函數

圖 3-3 架構
=TRIM( text )
去除頭尾空白字元
將 " Kaohsiung " 轉為純淨港口名稱。
=CLEAN( text )
消除 EDI / 報關系統匯出不可見控制碼
剔除 ASCII 0~31 的非列印換行字符。
=VALUE( text )
文字型數值轉換為計算數值
將字串 " 18500 " 轉為能計算的數字 18500。
=SUBSTITUTE( text, "$", "" )
剔除海運費幣別符號與千分位逗點
運費欄位淨化必備嵌套函數。
第三章 · 示範檔實作

提單主鍵去重 (Remove Duplicates)

圖 3-1 實務對話框
⚡ 4 步驟標準操作程序 (SOP)
  1. 步驟 1：選取資料範圍任一儲存格。
  2. 步驟 2：切換至功能區【資料】標籤頁 -> 點選【移除重複項】。
  3. 步驟 3：勾選「我的資料有標題」，點選「取消全選」後，單獨勾選【提單號碼(BL_NO)】與【訂艙代號】。
  4. 步驟 4：點選「確定」，系統即刻自動剔除第 4 筆重複提單（保留 29 筆唯一值）。
航運提示：切勿未經確認便全選所有欄位去重，因同一客戶可能分批寄送相同重量貨物，提單主鍵 (BL) 才是唯一判斷依據！
第三章 / 第四章 · 結構拆解

資料剖析 (Text to Columns) 拆解航商代碼

圖 3-2 實務對話框
提單代碼拆解應用場景

航運提單格式如 MSKU-8291034，透過設定分隔符號為「其他: -」，可一秒拆分出航商專屬代碼 (MSKU) 與流水號。

對應海運承攬實務好處： 迅速統計各航商（長榮、萬海、陽明、馬士基）年度訂艙櫃量與運費支出！
亦可搭配文字函數替代方案：
=LEFT(A2, 4) 提取前綴 / =MID(A2, 6, 7) 提取號碼

第四章 · 實戰練習檔

300筆航運案例進階實戰練習庫 (Shipping_Practice_300)

挑戰任務 01

提單與航商維度剖析

利用「資料剖析精靈」或文字函數，將提單字軌（如 MSKU-8291034）拆分出「航商代號」與「7碼流水號」。

=LEFT(A2, 4) / =RIGHT(A2, 7)
挑戰任務 02

全表去空格與去重審核

清洗出發港/目的港多餘空格，找出全表埋入的 5 筆重複訂艙提單並執行剔除，讓總數由 305 筆收斂為 300 筆。

=PROPER(TRIM(D2)) + 去重複項
挑戰任務 03

金額數值化與超重警示

將帶有 $ 符號之海運費純數值化；針對貨物重量 > 22,000 KG 之「超重櫃」設定條件式格式醒目提示。

=VALUE(SUBSTITUTE(TRIM(I2),"$",""))
第四章 · 參考答案

實戰挑戰題參考標準解題步驟 (SOP)

任務一解題：資料剖析極速切分

選取提單欄 -> 點選【資料】->【資料剖析】-> 選取「分隔符號」-> 勾選「其他」並輸入破折號「-」-> 目的地指定為相鄰兩空欄 -> 點擊完成，瞬間拆分 300 筆資料！

任務二解題：空格淨化與主鍵剔除

新增輔助欄輸入 =PROPER(TRIM(D2))，複製並「貼上值」覆蓋；隨後選取全表按【移除重複項】，勾選提單號碼為主鍵，精準刪除 5 筆重複單。

任務三解題：運費數值化與條件式格式化超重標註

套用嵌套公式 =VALUE(SUBSTITUTE(SUBSTITUTE(TRIM(I2),"$",""),",",""))；選取毛重欄 ->【設定格式化的條件】->【反白標示儲存格規則】->【大於 22000】，套用黃底紅字警示重櫃。
